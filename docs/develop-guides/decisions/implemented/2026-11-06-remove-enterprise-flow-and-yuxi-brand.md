# 移除示例流程后台和语析品牌显示

状态：implemented
类型：feature
Owner：backend/package/yuxi/config/static/info.template.yaml

## 问题

示例流程后台 `enterprise-flow` 和页面上的「语析」「Yuxi」名称、上游仓库入口，不属于当前部署要保留的产品标识。

## 决策

删除 `enterprise-flow` 及其决策记录。站点名称、页脚、登录名和侧栏回退名改为「知识库」。页面上指向语析仓库或文档站的入口一并移除。内置知识库类型在界面上显示为「内置」。智能体默认提示词不再自称语析。

## 替代方案

- 只停掉流程后台容器，保留代码。下次启动仍会带上这套示例服务。
- 只改品牌 YAML，保留页面里写死的 GitHub 和文档链接。那些入口仍会打开语析站点。

## 后果

`http://localhost:18080` 不再提供流程后台。已经在语析里添加的 `enterprise-flow` MCP 记录不会随代码删除，连接会失败，需要在扩展页面自行移除。内部包名、存储键和接口字段保持不变。

## 验证

页面源码不再包含「语析」或指向 `xerrors/Yuxi` 的链接。知识库类型标签单测改为断言「内置」。流程目录删除后，仓库内不再引用 `enterprise-flow`。
